Dashboard financiero personal

Aplicación web para centralizar y visualizar finanzas personales, construida con Python, Flask y SQLite, desplegada en un NAS local para uso privado.

Portfolio Hablar con mi CV
Objetivo

Convertir datos financieros en una vista clara y accionable

El dashboard organiza ingresos, gastos y movimientos para entender mejor la evolución del dinero, detectar patrones y tener una visión rápida del estado financiero personal. Está pensado como una herramienta práctica: sencilla de consultar, privada y mantenible.

Stack
PythonFlaskSQLiteHTML/CSSJavaScriptNAS local
Arquitectura

Backend en Flask para servir la aplicación y gestionar datos persistidos en SQLite. Frontend web ligero para consultar métricas, categorías y evolución financiera sin depender de servicios externos.

Despliegue privado

La aplicación está ejecutándose en un ordenador/NAS dentro de red local. Por privacidad y seguridad, no se publica el acceso interno en la web pública.
